# Executive Summary

## Project Overview

Identity Security with Entra is a hands-on project that I built to understand Microsoft Entra administration beyond simply studying for the SC-300 exam. My goal with this project is to work through identity security concepts the same way I would if I inherited an Entra tenant in a real organization and was responsible for securing it.

Throughout the project, I will assess the environment, identify risks, implement security controls, configure governance solutions, administer identities, troubleshoot issues, and document the reasoning behind every decision I make. Rather than focusing solely on passing an exam, I want to understand why these controls exist, what problems they solve, and how they are managed in production environments.

---

## Project Objectives

By the end of this project, I intend to demonstrate my ability to:

- Assess the security posture of an Entra tenant.
- Create and administer users, groups, and roles.
- Implement authentication controls.
- Configure Conditional Access policies.
- Manage privileged access using PIM.
- Develop governance workflows.
- Secure workload identities.
- Investigate identity-related incidents.
- Administer Entra through PowerShell.
- Align security controls with Zero Trust principles and Microsoft recommendations.
- Explain identity security concepts in a way that demonstrates practical understanding rather than memorization.

---

## Methodology

For this project, I am following a process that mirrors how I learn best:

Assess → Learn → Build → Test → Break → Fix → Document → Review

I want to understand not only how to configure features within Entra, but also how to evaluate their effectiveness, identify mistakes, troubleshoot issues, and improve the environment over time.
