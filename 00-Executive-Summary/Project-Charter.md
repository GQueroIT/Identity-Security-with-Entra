# Project Charter

## Project Name

Entra ID Security Posture Assessment

---

## Sponsor

This engagement is sponsored by leadership at 52 Logistics LLC, who requested the assessment after raising concerns about the state of identity security across their environment.

---

## Project Purpose

The purpose of this project is to assess the current security posture of 52 Logistics LLC's Microsoft Entra ID tenant and identify areas for improvement aligned with Zero Trust principles.

---

## Objectives

Going into this engagement, my objective is to assess the current identity controls in place across the tenant and review how privileged access is assigned and managed. I want to evaluate the authentication methods currently configured, identify the actual security gaps between where the tenant stands and where it should be, and recommend remediation strategies that address those gaps directly. From there, the goal is to reduce standing administrative access wherever it isn't justified and improve identity governance across the tenant overall.

---

## Deliverables

- Executive Summary
- Tenant Assessment
- Risk Findings
- Recommendations
