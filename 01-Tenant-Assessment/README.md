# 01 - Tenant Assessment

## Overview

The Tenant Assessment phase establishes the foundational knowledge required to understand and administer Microsoft Entra ID environments. This phase focuses on identity fundamentals, authentication methods, authorization concepts, and Zero Trust principles that serve as the basis for implementing secure Identity and Access Management (IAM) solutions.

This repository documents my progression through Microsoft Entra ID concepts while preparing for the SC-300 certification and developing practical identity engineering skills.

---

# Objectives

The objectives of this phase are to:

* Understand modern identity architecture.
* Learn authentication and authorization concepts.
* Study Microsoft Entra ID capabilities.
* Apply Zero Trust principles.
* Design identity architecture diagrams.
* Build a portfolio demonstrating IAM knowledge and technical documentation practices.
